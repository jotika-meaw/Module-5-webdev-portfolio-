# Module 5 - Web Development Portfolio

**Personal portfolio website created for the Module 5 web development course (HTML, CSS).**

[![Live Demo](https://img.shields.io/badge/Live_Demo-jotika--meaw.github.io-blue)](https://jotika-meaw.github.io/Module-5-webdev-portfolio-/)

## About

A course portfolio page with an about section, a "What I do" skills overview, a resume summary covering education and experience, and a contact form. Created as the Module 5 web development assignment.

## Features

- **About me** - intro and personal details
- **What I do** - skill areas (JavaScript, React/Vue, Node.js, Python and Django)
- **Resume summary** - education and experience
- **Contact form** - "Let's message me" section
- **Responsive layout**

## Tech Stack

- HTML5
- CSS3

## Run Locally

```bash
git clone https://github.com/jotika-meaw/Module-5-webdev-portfolio-.git
cd Module-5-webdev-portfolio-
```

Open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```
